# Tubego: matriz de aceptación del MVP

Auditoría de tarjetas PLA-227–257 y criterios de Linear, código hasta QA 397cd2b y runtime d508536, con cadena de PR 31/32/34/35, más corrección de calidad propia 1b1e68b integrada mediante PR36 en main 9fa3a24. Fecha: 2026-10-10. No se cambiaron estados en Linear. Los estados de esta matriz son técnicos; una tarjeta marcada Done en Linear no sustituye validación operativa.

## Resultado y límites de evidencia

El harness integral detectó una brecha P1 real: el selector 720p excluye formatos cuya altura yt-dlp no conoce (fuente pública directa Blender), y el worker termina con format_unavailable. La UI ya produce y envía correctamente la solicitud; falta corregir el selector y repetir con base/DB fresca sin cambiar la selección a best para ocultar el fallo. Los avisos de calidad y motivos de errores de origen sí se corrigieron en 1b1e68b. Quedan validaciones operativas concretas: cadena única de APK con sesión instalada tras login API, pegando URL pública → cola durable → worker real → descarga local y confirmación; El correo SMTP y el supervisor real tienen resultados PASS separados reportados por root; debe conservarse su evidencia exacta junto al informe de despliegue. Se está preparando un harness reproducible para la cadena móvil completa. No se afirma funcionamiento universal de portales, eliminación remota inmediata estando offline ni ejecución ilimitada en background.

Evidencia acumulada: root reportó 280 pruebas backend PASS tras QA 397cd2b, Android build/lint/JVM PASS, native QA 4 PASS; idioma nativo 3 PASS; avisos de calidad backend 41 PASS y nativo 1 PASS. Existe evidencia reproducible de worker real descargando vídeo y MP3 de fuentes públicas W3C/Blender vía proxy restringido, conversión FFmpeg, Range y confirmación autenticada. Existe otra evidencia nativa independiente de TLS real, descarga 16 MiB parcialmente pausada, reanudación como job con pantalla apagada y confirmación SHA; VLC oficial 3.7.1 tuvo PiP y audio con pantalla apagada PASS en API 35. Esto no equivale todavía a una prueba única de toda la experiencia de usuario.
