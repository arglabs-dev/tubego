# Tubego: matriz de aceptación del MVP

Auditoría de tarjetas PLA-227–257 y criterios de Linear, código hasta QA 397cd2b y runtime d508536, con cadena de PR 31/32/34/35, más corrección de calidad propia 1b1e68b integrada mediante PR36 en main 9fa3a24. Fecha: 2026-10-10. Estados técnicos de aceptación: Linear se actualiza con esta evidencia. Una tarjeta marcada Done en Linear no sustituye validación operativa del despliegue concreto.

## Resultado y límites de evidencia

El harness integral descubrió y permitió corregir una brecha P1 real: el selector 720p excluía formatos cuya altura yt-dlp no conocía. Tras fix `a896aa5`, la cadena APK con sesión instalada desde login API, URL pública pegada, confirmación, cola durable, worker real y archivo local confirmado pasó en 10.276s sobre revisión exacta `e3bdea371efbb0587d827432dc720f86224065bb`. No queda una brecha MVP obligatoria conocida. El correo SMTP y el supervisor real tienen resultados PASS separados reportados por root; su configuración operativa debe conservarse junto al informe de despliegue. No se afirma funcionamiento universal de portales, eliminación remota inmediata estando offline ni ejecución ilimitada en background.

Evidencia acumulada: root reportó la suite backend final 301 PASS (40.90s) con código integrado de revisión e3bdea; la suite anterior main9fa3a24 también pasó 281 pruebas (49.05s), Android build/lint/JVM PASS, suite nativa integrada 17 PASS (7.556s); idioma nativo 3 PASS; avisos de calidad backend 41 PASS y nativo 1 PASS. Existe evidencia reproducible de worker real descargando vídeo y MP3 de fuentes públicas W3C/Blender vía proxy restringido, conversión FFmpeg, Range y confirmación autenticada. La repetición nativa final TLS sobre APK integrado e3bdea pasó en 17.393s: descarga 16 MiB parcialmente pausada, Range/reanudación como job con pantalla apagada, confirmación SHA y limpieza por revocación; VLC oficial 3.7.1 tuvo PiP y audio con pantalla apagada PASS en API 35. La prueba integral móvil adicional pasó y se conserva en docs/evidence/mobile-source-e2e-2026-10-10.json. Utiliza login API/SessionStore de fixture aprobado y fuerza jobs reales; no incluye LoginActivity/Main onboarding ni prueba espontaneidad/latencia del OS.

## Fuera del primer MVP

PLA-258 iPhone, PLA-259 Google login y PLA-260 cuotas por usuario quedan Backlog. No hay carpetas/listas ni reproductor embebido. La investigación de minuto exacto VLC no bloquea el lanzamiento.

Los párrafos históricos de MOBILE_ARCHITECTURE/MEDIA_PREFERENCES/DEVICE_DELIVERY sobre pantalla inicial, preferencias solo online y revocación de stream como futura se actualizaron en este cierre documental.
